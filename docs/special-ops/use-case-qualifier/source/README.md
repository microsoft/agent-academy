# Source Files

## welcome-card.json

This is the Adaptive Card JSON for the `ConversationStart` system topic. Paste it into the Adaptive Card editor in Copilot Studio (Topics > System tab > Conversation Start > Send a message node > Adaptive Card tab). Replace the placeholder logo URL (`https://placehold.co/200x48/0078D4/ffffff?text=Your+Logo`) with your organization's actual logo URL before saving.

## qualifier-instructions.txt

This is the full instruction block for the agent. Paste it into the Instructions editor in Copilot Studio (Overview tab > Instructions > Edit). Before saving, replace every instance of `[YOUR_EMAIL]` with the email address that should receive qualified leads. The file is under 8,000 characters by design so it fits within the Copilot Studio instruction limit without truncation.
