# Webinar Brand and Editorial Guide

Fictional training data for Zava's internal documents and presentations.

## Document style

- Start new documents and presentations with INTERNAL DRAFT - NOT SENT.
- After an explicit internal-review instruction, replace that label only on the
  named deliverable with FINAL - INTERNAL PLANNING.
- Final planning status does not authorize spending, invitations, or publication.
- Use the exact event title: Better Project Handoffs.
- Use clear headings, short paragraphs, and concise lists.
- Use a simple navy heading color with a teal accent, if formatting permits.
- Keep tables readable and avoid using color alone to communicate meaning.

## Language

Use plain English and a practical, supportive tone.
Address project leads rather than an unspecified general audience.
Distinguish a registration target from actual registrations. Only report actual
results when a supplied post-event source supports them.
Write "budget ceiling" rather than "approved budget."

## Accuracy

Separate confirmed facts, planning decisions, proposed next actions, and
open questions. Label suggestions as suggestions.
Name the source files used in a short Sources section in each document.
Do not turn proposed wording into an approved customer announcement.
